# Contributing

Bug reports, ideas and pull requests are welcome.

- Open an issue first for larger changes.
- Run `cargo test --locked` before sending a pull request.
- Keep the privacy promise in [PRIVACY.md](PRIVACY.md): no new network access, and nothing that stores prompts or responses.
- Never include real usage history, project names or paths in issues, tests or screenshots. Use `--demo` for screenshots and synthetic data in tests.
